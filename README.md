# 知行金融学院 · Aurum Academy

一个**零依赖、纯静态**的金融知识学习系统：从宏观经济到公司估值、从技术分析到基金定投、
从交易模式到纪律风控——九大阶段循序渐进，配间隔重复记忆引擎，形成「学 → 练 → 错 → 忆 → 用」完整闭环。

## 快速开始

- **方式一（推荐）**：右键 `serve.ps1` →「使用 PowerShell 运行」，自动打开浏览器访问 `http://localhost:8787`
- **方式二**：直接双击 `index.html`（功能完整；若浏览器限制本地存储，改用方式一）

无需安装 Node / Python / Git，任何现代浏览器（Edge / Chrome）即可。

## 学习闭环设计

1. **学** — 每课结构：导语 → 分节精讲 → 常见误区（逆向学习）→ 要点卡
2. **练** — 每课测验 ≥60% 通过；阶段测验 ≥75% 解锁下一阶段；毕业考 ≥85%
3. **错** — 答错的题自动进入错题本 + 记忆循环，重练全对即消灭
4. **忆** — 要点/辨析/错题自动生成记忆卡，SM-2 改良算法安排复习间隔；
   掌握度随时间衰减、随复习回升（知识地图圆点亮度可视化）
5. **用** — 纪律工坊：盘前十问清单、交易计划七要素（盈亏比自动计算）、交易日志与合规自评

另有：每日 30XP 打卡、连续天数火焰、经验等级（见习研究员 → 首席投资官）、
每日金句轮换、复习压力 7 日预报、12 周学习日历热力图、数据导出/自由模式。

## 目录结构

```
aurum-academy/
├── index.html          # 单页应用入口
├── serve.ps1           # PowerShell 静态服务器（零依赖）
├── css/                # 设计系统：磨砂玻璃 + 淡金主题
└── js/
    ├── core.js         # 状态存储 / 路由 / 经验打卡
    ├── srs.js          # 间隔重复记忆引擎（SM-2 改良 + 掌握度衰减）
    ├── ui.js           # 图标 / 环形进度 / 撒花 / 金句
    ├── data/           # 十大阶段课程内容（可独立编辑维护）
    └── views/          # 首页/地图/阶段/课程/测验/复习/错题/统计/工坊
```

> 数据保存在浏览器 localStorage（键 `aurum_academy_v1`），在「数据」页可导出 JSON 备份。
> 学习内容仅用于金融知识教育，不构成任何投资建议。
